# 第一部分 · 方案

## 0. 选型判据（先给结论，理由见第二部分）

| # | 判据 | 结论 |
|---|---|---|
| **1** | 单纯量、缓慢变化、只需读趋势 | **机械**（指针 / 鼓轮 / 带式） |
| **2** | 需要**精确设定的数值**（目标值） | **机械鼓轮**（旋钮直驱，无需供电） |
| **3** | 图形**随模式改变几何**（箭头、游标、扇区、剖面） | **CRT** |
| **4** | 需要**多源合成**的一张图 | **CRT** |
| **5** | 离散状态 / 阈值 / 告警 | **机械灯板 + 旗标** |
| **6** | 断电后仍须可读 | **无源机械**（摆、磁罗盘、旗标） |

**结果：15 组仪表中只有 4 项必须 CRT，其余全部机械。**

> 术语区分：**无源机械**（摆、磁罗盘、机械旗）与**电动伺服机械表**（synchro/servo 驱动的指针、鼓轮）。后者仍须供电（接应急汇流条），但结构简单、无软件、失效模式可见。下文"机械"默认指后者，真正无源的会特别标注。

### 1.5b VSI（垂直速度表）：**单针 + Ṡ 游标**

分解恒等式：

\[
\dot z \;=\;\underbrace{\nabla S\cdot\mathbf V}_{\dot S\ \text{地形遭遇}}\;+\;\underbrace{\dot{\text{gap}}}_{\text{指令}}
\]

| 项 | 型式 | 说明 |
|---|---|---|
| **针（白）** | ż 实际垂直速度 | **阻尼后**（见下） |
| **游标（红，伺服驱动）** | Ṡ = ∇S·V | 由地形数据 + 速度自动定位 |
| 读法 | **针压游标 = 纯地形跟随（正常）**；偏离量 = 实际间隙闭合率 | — |
| 量程 | **±2.5 m/s**（Ṡ 0.88 + ġap 1.5 = 2.38） | — |
| 绿带 | ±0.9 m/s，标 `terrain-following only` | — |
| **ġap** | **不上表盘**，作为数字显示在 zRef 升降计划区 | 它是差值，不是独立测量 |
| 机械阻尼 | **τ ≈ 1–2 s**（油阻尼 / 节流） | **必需**，见第二部分 §9 |

> **不是双针、也不是两块表**：Ṡ 是 ż 的参照/解释，不是并列测量；常态两者恰好重合，而**双针重合是最难读的状态**（互相遮挡且无法判断单针是否卡住）。同盘单针 + 游标把"重合"变成最干净的读数。

> **告警语义取消**：Ṡ_max = s_max·V_max = 0.04×22 = **0.88 < r_max = 1.0** ⇒ `FIELD_RATE` 告警在现行参数下**不可触发**，vLimit 恒等于 V_max。它现在是纯参考游标。
> （`instruments.js` 的 `fieldRate.alarmReachable` 会给出该判据，供参数变更时复核。）

# 第二部分 · 理由

## 1. 为什么绝大多数用机械

1. **慢系统**：本平台的被控量（AGL、坡度、总重、zRef）全是**慢变量**——高度变更 15 分钟、升降速率 1.5 m/s、坡度 2°。慢量的最佳显示是**指针**（读趋势、读偏差），不是数字。
2. **断电仍需可读**：弹簧是被动的，失去电力**群玉阁不会掉**（这是 fail-frozen 的前提），但也**下不来**。此时必须仍能看到姿态、高度、推进器状态——CRT 全黑是不可接受的。
3. **无软件、失效可见**：机械表的失效是"指针卡住/抖动"，一眼可见；CRT 的失效可能是"显示了一个错的值"。对安全关键量（升限、离地、饱和）这一点是决定性的。
4. **设定值不需要电**：MCP 的鼓轮由旋钮直驱，即使全船断电，机组仍能设定目标；来电后自动生效。这与"zRef 必须接应急汇流条"形成互补。
5. **扫描式可读性**：机械表可设计成"正常时指针排成一行"，异常自动跳眼（见 §4）。

## 2. CRT 的 4 项为何无法机械

| 项 | 不可机械的原因 |
|---|---|
| 圆表 | 需要**随艏向旋转的卡 + 变长变向的箭头 + 两个独立游标 + 两个可变扇区**。机械 RMI 只能做"卡 + 一针"。 |
| 地形剖面 | 需要沿**瞬时航迹**取 11 点并叠加 S/T/坡度——机械等价物是"可旋转的立体地形盘 + 探针"，量程与分辨率都不现实。 |
| 能力极坐标 | 需要扫描 24 艏向 × 速度求 v_max，且随风、载重实时变。 |
| 文本页 | 字母数字（ETA、告警明细）只能电子。 |

**折中做法**：把这三个 CRT 图里**最关键的那一个数**提为机械表——
- 地形剖面 → **前视最小离地**（机械表）
- 能力极坐标 → **可行艏向扇形叠加到圆表**、**可行占比**（数字）
- 文本页 → **升限余量、可失石数**（机械双针 + 灯柱）

即：**CRT 用于"看图"，机械用于"看命"。**

## 3. 两个本平台特有的机械可行性

### ① 摆式倾角仪（无源姿态备份）可用

传统飞机不能用摆作地平仪（机动加速度使摆误指）。但群玉阁：

- 正常垂向加速度 ≈ **0.01 g**（1.5 m/s 升降经 S 曲线平滑）
- 水平加速度 ≤ 0.5 m/s²（≈0.05 g）
- 姿态变化周期 1.9–5.5 s，摆的响应足够快

⇒ **摆的误差 <1°**，完全够用。一个**水准泡/摆式倾角仪**就是断电后最可靠的姿态参考，且对一艘"会飞的船"而言在概念上完全贴切。

### ② 升限可用纯机械的"对数凸轮链"算出

\[
z_{ceiling}=\lambda\big[\ln(nF_0)-\ln W\big]
\]

- \(\ln W\)：一根**对数凸轮**（总重轴 → 转角）
- \(n\)：一个**9 级步进凸轮**，由失石继电器驱动（失一块，凸轮跳一级）
- 与固定基准相减 ⇒ 升限指针

全程无电子、无软件。**双针表**（AGL 针 vs 升限针）于是成为一个纯机械的"coffin corner"显示器——两针逼近即危险，这个语义不需要任何计算就能读懂。

## 4. 巡检规则："指针排齐"

| 仪表组 | 正常图案 | 异常表现 |
|---|---|---|
| 7 个推进器表 | **全部指 0** | 非零 = 有扰动或该配平 |
| 9 个石头出力表（水平时） | **全部对齐（100%）** | 偏离 = 载荷不均 / 石头异常 |
| 3×3 出力表（斜坡 FOLLOW） | **平滑梯度**（前后或左右渐变） | 梯度被打乱 = 异常 |
| 9 个 zRef 鼓轮 | 集体值 ± 平滑差动 | 单格跳变 = 卡滞 |

> ⚠ **实测提醒**：斜坡 FOLLOW 时石头出力为 **117.7% / 82.3%**（非均匀 100%）。
> 成因值得注意：平台已基本对齐坡度（φ=2.42° vs 坡度 2.12°），两者的**差值只有 0.30°**（摆式修正项 \(s·BM/(BM-d)\)）；
> 但 δ₀ 仅 0.30 m ⇒ 这 0.30° 的残余在 ±10 m 的石阵上造成 ±0.053 m 的间隙差 ⇒ **±17.7% 的载荷再分配**。
> 所以"指针排齐"只在水平时成立；坡地上的正确判据是"**平滑梯度 + 梯度方向对应坡度**"。必须写进检查单，否则会被误判为故障。

## 5. 3×3 的同构性不是排版偏好

- **防选错块**：紧急时把 3×3 排成与物理阵列一致（前排在上、左列在左），是最有效的防错。
- **图案即信息**：9 个指针的角度构成一张"载荷分布图"——机组一眼能看出载荷偏在哪一侧，这比 9 个数字有用得多。
- **权重靠表圈颜色**：角石（ΔGM −37/−333）、边中（0/−333 或 −37/0）、中心（0/0）用表圈刻色区分，**无电子、不会看错**。

## 6. 游标（bug）统一用于"同一刻度上的限值"

| 表 | 游标 | 含义 |
|---|---|---|
| 空速表 | 红游标 | V ≤ r_max/s（随坡度自动移） |
| 总重表 | 红游标 | 载荷线（随目标 AGL 移） |
| ALT 鼓轮 | 红游标 | 升限 −150（与升限针同源凸轮） |
| 离地表 | 红游标 | 最小间隙（默认 200 m） |
| 地平仪 | 游标 | 坡度目标（FOLLOW 时平台对齐它） |
| **VSI** | **红游标** | **Ṡ = ∇S·V（参考基准，非限值）**；针压游标 = 纯地形跟随 |

**一致的好处**：所有"限值/基准"都用同一种视觉语言（红色游标画在被限量的同一刻度上），不需要跨仪表换算，也不需要记忆哪个数字对应哪个极限。

> VSI 的游标是唯一的**非限值**游标——它标的是"正常值在哪"，不是"极限在哪"。这是有意的：随地形飞行时 ż 本来就该非零，把它标成"红区"是错的。

## 7. 与既有决策的一致性

| 既有决策 | 本方案的呼应 |
|---|---|
| 删除 MCP 的 V/S 旋钮 | 保留 **VSI 指示器**（测升降率），不保留 **V/S 旋钮**（不能指令升降率）——测量与控制分离 |
| 随地形自动爬升（Ṡ） | VSI 上的 Ṡ 游标解释了"没指令却在爬升"；针压游标 = 纯跟随 |
| 稳态推进器零出力 | 巡检规则"7 个指针全指 0"；VSI 则相反——**针压游标才是稳态** |
| 不用指示灯表达"模式" | `PENDING` 旗标表达的是**草稿与生效的差异**，不是模式；`LEVEL/FOLLOW` 用**带灯拨动开关**（开关位置即状态） |
| 圆表永久 HDG UP | 卡片顶端读数 = 艏向，**自明**；CRT 角落刻字 `HDG↑`（刻字不是灯） |
| 中心石失效零刚度损失 | 中心表圈**无环**，机组一眼看出它"只供升力" |
| 载荷线由升限决定（+7344 t） | 总重表红游标固定在 **22,344 t**（AGL=749 时），远紧于稳定性的 107,581 t |
| zRef 接应急汇流条 | MCP 鼓轮**无需电**即可设定；伺服驱动部分接应急汇流条 |
| 受控着陆优先于撤离 | 断电可读集（摆、鼓轮、灯板）保证"能判断、能等待" |

## 8. 需要注意 / 待决策

1. **伺服机械表仍需电**：真正的无源只有摆式倾角仪、磁罗盘、机械旗标、鼓轮设定。其余需接**应急汇流条**——这与"zRef 致动须接应急汇流条"是同一条要求。
2. **升限凸轮的温度/磨损漂移**：对数凸轮是机械函数发生器，长期使用会有误差。建议保留一个 **CRT 数值**作为交叉校核（双针表为主、CRT 为辅）。
3. **9 段"可失石数"灯条**：它是"两针夹角 + 当前 n"的离散化结果，需要一个小比较器——建议用**继电器级**逻辑而非软件。
4. **石头出力表量程 0–150%**：平地恒为 100%；斜坡 FOLLOW 已达 **117.7% / 82.3%**（残余倾角 0.30° 所致），再叠加失石/阵风可能更高。故刻度到 **150%**，100% 处加绿带（99–101%）。
   **推论**：不能用"指针是否排齐"判断故障，必须看**梯度是否平滑且与坡度一致**。
5. **CRT 数量**：建议 4 台（2O 圆表 1 + 中台 MFD 1 + FE 1 + 备用 1），任一可显示任一页。
6. **是否需要机械 RMI 备份**：圆表必须 CRT，但**只指示艏向**的备份可用机械 RMI（卡 + 一针）。若认为必要可加。
7. **摆式倾角仪的阻尼**：摆需要阻尼才能读，通常用油阻尼——这是无源的（无需电）。需确认在 1.9 s 俯仰周期下是否够快。（与下面的 VSI 阻尼属同一类问题，建议一起定。）

## 9. 为什么 VSI 必须阻尼（实测）

**ż 含 T_z = 1.10 s 的弹簧模态。** 自动驾驶阻尼正常时会在 1.7 s 内压掉它，但**阻尼失效时恰恰是最需要看 VSI 的时候**——此时无阻尼 ż 是不可读的。

实测（斜坡地形、关掉自动驾驶阻尼、V=22 m/s）：

| | 峰峰值 |
|---|---|
| **无阻尼 ż** | **2.32 m/s** |
| **阻尼后（τ=1.5 s）** | **1.05 m/s**（降到 45%） |

信号本身只有 ±0.88 m/s，**摆幅是信号的两倍多**——指针会在正负之间疯抖，读不出任何信息。

⇒ **VSI 需要 τ ≈ 1–2 s 的机械阻尼**（油阻尼或节流）：滤掉 1.1 s 的弹簧模态，同时保留秒级的指令变化。

## 10. ż 单独看会双向骗人（VSI 必须有参照物）

\[
\dot z=\dot S+\dot{\text{gap}},\qquad \dot S_{\max}=s_{max}V_{max}=0.88,\quad \dot{\text{gap}}_{\max}=1.5
\]

| 地形 | 指令 | **ż（VSI 读数）** | 真实 gap 速率 | 问题 |
|---|---|---|---|---|
| 上升 +0.88 | 保持（无指令） | **+0.88** | **0** | "没指令却在爬升" —— 正是要解释的现象 |
| 上升 +0.88 | 应急下降 1.5 | **−0.62** | **−1.5** | ⚠ **低报**闭合率（读数只有真实的 41%） |
| 下降 −0.88 | 保持（无指令） | **−0.88** | **0** | ⚠ **假警报**：间隙纹丝不动，指针却在"下降" |
| 下降 −0.88 | 应急下降 1.5 | −2.38 | −1.5 | 高报 |

四行里三行有问题 ⇒ **单独的 VSI 既会漏报也会误报，必须有 Ṡ 游标作参照**。这也正是它不能做成双针、而要做成"针 + 游标"的原因：重合 = 正常，是最干净的读数。
