> 配套代码：
- `jade-chamber.js` —— **物理层**（几何、质量、浮空场、刚体积分），不含任何控制

## 1. 总体模型：两尺度场

浮空石的力由**两个尺度叠加**，二者承担完全不同的职责。

| | 慢包络（Yukawa / 屏蔽场） | 快弹簧（局部刚度） |
|---|---|---|
| 形式 | \(F_{\max}(g)=F_0e^{-g/\lambda}\) | \(f=k\,(z_{ref}-g)\) |
| 参数 | **λ = 500 m** | **δ₀ = 0.30 m** |
| 管什么 | 自然悬浮高度、海拔包络、升限 | 平衡刚度、稳定性、阻尼 |
| 时间尺度 | 慢（τ_s = 300 s） | 瞬时（T_z = 1.10 s） |

**理由**：纯指数场会得出 δ₀ = λ = 500 m（软 1700 倍），与"放置多少建筑都不会下沉"冲突且要求 530 m 见方基盘。拆成两尺度后，λ 只负责海拔包络，局部刚度仍取 δ₀=0.3 m，全部既有结论得以保留。

### 力的方向
**恒为世界竖直方向**（不沿场法线）。这样坡面不产生 \(W\tan\alpha\) 的水平力，s_max 不必被压到 0.002。

## 2. 平台几何与质量特性

| 量 | 值 |
|---|---|
| 外接长方体 | 2a × 2b × 2c = **120 × 120 × 80 m**（a=b=60, c=40） |
| 结构干重 M_dry | 10,000 t |
| 浮空石总质量 m_s | **5,000 t**（= 0.5·M_dry，占全重 33.3%） |
| 总质量 M_nom | **15,000 t**，W = 147.15 MN |
| 升重比 α | **20** |
| 重心 z_CG | ≈ **−9.0 m**（石头压载效应） |
| d = z_CG − z_CB | ≈ **27.9 m** |

**浮空石是死重**（密度≈岩石）是这一构型的稳定基础：33% 的质量压在基盘上，重心天然低于浮心。

## 3. 浮空石阵列与力律

### 3.1 阵列
9 块，3×3，**位于 z = −c = −40 m**（基盘平面）：

```
x ∈ {−30, 0, +30}        y ∈ {−10, 0, +10}
```

面积二次矩：Σx² = 5400 m²，Σy² = 600 m²（**3:1 细长 ⇒ 滚转是弱轴**）。

### 3.2 力律（核心）

\[
g_k = Z + z_s + y_k\phi - x_k\theta - S_k,\qquad
\boxed{f_k=\operatorname{clamp}\Big(k\,(z_{ref,k}-g_k),\;0,\;F_0e^{-g_k/\lambda}\Big)}
\]

- \(k = W/(9\delta_0) = 5.45\times10^7\) N/m，总 9k = 4.9×10⁸ N/m
- \(F_0 = \alpha m_s g/9 = 109\) MN/石；9F₀ = 981 MN
- `clamp` 的下界 0 是唯一的"停机"条件：**zRef 低于当前间隙 ⇒ 力为负 ⇒ 夹到 0 ⇒ 自由落体**

### 3.3 环境力矩（形式不变）

\[
\mathbf M_{env}=\sum_{k=1}^{9}(\mathbf r_k-\mathbf r_{cm})\times(f_k\hat{\mathbf k}_b)
\]

**关键**：因为 f_k 依赖 g_k，倾斜时 g_k 随 \(x_k\theta, y_k\phi\) 变化 ⇒ 分布支承恢复力矩 \(k\Sigma x^2\theta\) **自动出现**，地形力矩也自动包含。**无需新增项。**

### 3.4 ±1% 的新身份
不再是操纵量，而是**制造公差 / 健康阈值**：单石实测出力偏离 \(k(z_{ref}-g)\) 超过 1% ⇒ `STONE DEV` 告警。残余影响可忽略（总力误差 RMS 0.333%W → 高度偏移 1.00 mm）。

## 4. 场参考面与地形

| 项 | 决策 |
|---|---|
| 地形接口 | `elevationFt(xNM, yNM) → ft`（`terrain.js`，内部 `elevationM = elevationFt(x/1852, y/1852)×0.3048`） |
| 场参考面 S | 地形的**锥形膨胀**（最小 s-Lipschitz 优函数）：平缓处=地形、尖峰抹宽成坡度 s_max 的锥、窄谷架桥 |
| 性质 | **S ≥ T**（间隙恒为离地间隙的安全下界）；\|∇S\| ≤ s_max |
| 坡度限 s_max | **0.04**（2.29°） |
| 变化率限 r_max | **1.0 m/s**（> s_max·V_max = 0.88，保证无滞后） |
| 限速 | **V ≤ r_max / s**（s=0.04 ⇒ 25 m/s，与 azimuth 上限 22 兼容） |

预设地形：`flat / sea / hills / ramp / ridge / peak / liyue`。

## 5. 运动方程

\[
\begin{aligned}
M\ddot Z &= \sum f_k - Mg + F_{thr,z} - D_z\\
I_x\ddot\phi &= \sum y_k f_k + M_{thr,x}\\
I_y\ddot\theta &= -\sum x_k f_k + M_{thr,y}
\end{aligned}
\]

水平/偏航通道与地形无关，**完全不变**，仍由 azimuth 负责。

### 模态特性（实测）

| 模态 | 参数 | 周期 |
|---|---|---|
| 垂荡 | ω = 5.72 rad/s | **1.10 s** |
| 滚转 | GM = 194 m | 5.5 s |
| 俯仰 | GM = 1972 m | **1.91 s** |

**俯仰轴比滚转轴硬 9 倍、频率高 3.3 倍 ⇒ 阻尼力矩需求 3.5 倍，是薄弱环节。**

### 积分
`dt = 0.02 s` 足够（ω_pitch = 3.3 ⇒ dt·ω = 0.067）。clamp 的 min/max 切换需平滑，否则触顶边界会抖振。

## 6. 自动驾驶

### 6.1 总原则：三层架构

| 层 | 时间尺度 | 手段 | 能耗 | 管什么 |
|---|---|---|---|---|
| L0 弹簧 | 瞬时 | 石头刚度 | **免费** | 高度、水平姿态 |
| L1 推进器 | 1–60 s | 速率反馈 | 耗能 | **阻尼**、水平位置、航向 |
| L2 zRef | **300 s** | 集体/差动 | **免费** | 高度设定、静倾配平 |

### 6.2 分通道

| 通道 | 控制律 | 变化 |
|---|---|---|
| **垂向 Z** | **删除位置伺服**；改 skyhook 阻尼 \(F_z=-c_z\dot{\bar g}\)，\(\dot{\bar g}=\dot Z-\dot S_{mean}-(y\dot\phi-x\dot\theta)\) | 爬升（\(\dot Z=\dot S\)）时阻尼力为零 |
| **姿态** | **角速率阻尼** \(M=-c_\omega\omega\) 为主；坡度前馈 \((\phi_{cmd}=s_y,\ \theta_{cmd}=-s_x)\) | 稳态零出力 |
| **水平 / 偏航** | PD（不变） | 增加限速 \(V\le r_{\max}/s\) |
| **垂向分配** | 可重构最小二乘（保留 v1 的成果） | 力矩残差 1e-9 量级 |

阻尼系数（ζ=0.1）：\(c_z=1.72\times10^7\)，\(c_{roll}=5.02\times10^9\)，\(c_{pitch}=1.77\times10^{10}\)。

**自诊断规则**：推进器出现**持续非零输出** = 该做 zRef 配平了。

### 6.3 推进器配置

| | 位置 | 推力 |
|---|---|---|
| 垂推 ×4 | (±7a/8, ±3b/8, −c/2) | 单台 ≤ 5%W，合计 20%W |
| azimuth ×2 | (0, ±5b/6, 0)，全向 | 单台 ≤ 2%W，合计 4%W；偏航权限 294 MN·m |
| APU | (0, 0, −c)，**纯发电机** | 推力功能已删除 |

### 6.4 弹簧区 vs 触顶区的推进器权限

| | 上（20%W） | 下（8%W） |
|---|---|---|
| **弹簧区（正常）** | **+6.0 cm** | **−2.4 cm** |
| **触顶区** | +112 m | −38 m |

**⇒ zRef 是唯一真正的高度手段。** 推进器在垂向上只有厘米级权限。

## 7. 失效与降级

| 情景 | 表现 | 处置 |
|---|---|---|
| **单石失效** | 下沉 **8.5 cm**，静倾 0.78°，推进器 **0%W** | 无需抛压载；差动 zRef 配平 12.6 cm |
| **坡度跟随** | 自动倾斜 = 坡度（实测 **2.42°**），推进器 0.01%W | 免费；LEVEL 模式用差动 zRef 配平 |
| **垂推失效 1 台** | LS 重构 → 回 0.000° | 固定分配器会摆到 51.6°，必须重构 |
| **刚度丧失** | 发散 τ ≈ **2.3 s** | 推进器仅回收 **3.70°** ⇒ 只能撤离 |
| **触顶（zRef > 升限）** | 包络饱和 ⇒ 有效刚度塌缩 ⇒ GM ≈ −27.8 m ⇒ **翻覆** | 升限保护硬限幅 |
| **zRef 瞬时跳到 gap 以下** | clamp=0 ⇒ **自由落体 121 m/s**（110 GJ ≈ 26 t TNT） | 速率限 + S 曲线是唯一屏障 |
| **失 ≥ 5 块石** | 垂推顶不住，必沉 | 立即下降 + 疏散预令 |

### 已删除的功能
- ❌ 减石降高（危险且无用：升限瞬时跌落 ⇒ 包络饱和 ⇒ 16 s 翻覆）
- ❌ 抛压载恢复浮力（弹簧自动吸收）
- ❌ "烧油即补水"（弹簧吸收，毫米级）
- ❌ APU 推力（改为纯发电，但**保阻尼是安全关键**：自然阻尼 ζ≈1.3e-5，摆幅半衰 224 min）
- ❌ 单石隔离电门（lore 与安全性双重排除）
- ❌ 座舱内任何"解除激活"功能

## 8. 高度与升限

\[
\boxed{z_{ceiling}=\lambda\ln\frac{n\cdot F_0}{W}}
\]

| 层 | AGL |
|---|---|
| 最大升限 | **948.6 m** |
| 实用升限 | **749 m**（留 200 m ⇒ 容忍失 2 块） |
| 过载升限 | 1060 m（触顶后靠 20%W 再上 112 m） |

**升限余量的直接读数 = 还能坏几块石头**：

| AGL | 余量 | 可再失石 |
|---|---|---|
| 300 m | 649 m | 6 |
| 500 m | 449 m | 5 |
| **749 m** | 200 m | **2** |
| 850 m | 99 m | 1 |

### zRef 慢回路
- 一阶 **τ_s = 300 s**；速率限 **1.5 m/s**（速率限仅在 |Δz| > 450 m 时生效）
- **分辨率要求**：定高 1 m ⇒ F₀ 精度 **0.2%**
- **fail-frozen**（失电保持最后位置），必须接应急汇流条 + 手摇备份（0.1 m/s，降 500 m = 83 min）
- **应急下降 = 旁路 τ**（不旁路速率限）：749 m 从 ~37 min 缩到 **8.3 min**

### 为什么 1.5 m/s 不是物理上限
阶跃会激励 \(u/\omega_z\) 振幅，需 \(u < \delta_0\omega_z = 1.72\) m/s；但 **S 曲线上升时间 ≫ 1/ω_z = 0.17 s 时不激励振荡**。阻力也不构成限制（5 m/s 仅 0.11%W）。

**真正禁止的是"zRef 瞬时跳变"，不是"高速率"。**

## 11. 决策理由（摘要）

1. **两尺度而非纯指数** —— 纯指数使 δ₀=λ=500 m，与"不下沉"冲突且需 530 m 基盘；两尺度各自负责"海拔包络"与"局部刚度"，互不干扰。
2. **力恒世界竖直** —— 避免坡面产生 \(W\tan\alpha\) 的巨大水平力，使 s_max 可维持 0.04。
3. **删除垂向位置伺服** —— 弹簧已定义平衡（gap = zRef − δ₀），推进器既无必要也无能力（±6 cm）去覆盖它。
4. **速率反馈而非位置伺服** —— 无源阻尼器对任意增益无条件稳定，对多时间尺度系统鲁棒性极佳，且稳态零出力。
5. **升限而非稳定性作载荷线** —— 弹性无上限，超载不会"托不动"，只会沉到触地；GM 与 W 无关（自相似）。
6. **fail-frozen** —— "失电自动回默认高度"会造成高度突变；冻结虽下不来（推进器仅 6 cm），但不会掉。
7. **石头占 1/3 质量是稳定基础** —— 死重压载使重心天然低于浮心，兑现"浮生石是地基材料而非气囊材料"的设定。
